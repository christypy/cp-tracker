# 划算度帳本 · CP值紀錄網站

手機、電腦都能用的靜態網站，透過 Google 試算表存資料，GitHub Pages 免費架站。

- 輸入「克數」「價格」馬上算出 `$/g`（CP值）
- 新增品項會直接寫進你的 Google 試算表
- 表格自動依 `$/g` **由低到高**排序（越低越划算）
- 可依類別篩選、關鍵字搜尋
- 同類別品項會依 CP 值三分位自動標色：🟢划算 / 🟡普通 / 🔴偏貴

檔案說明：
- `index.html` — 網站本體，只有這一個檔案，直接部署即可
- `Code.gs` — 貼到 Google Apps Script 的後端程式碼
- `初始資料匯入.csv` — 你原本記錄的資料，已幫你整理好可直接匯入試算表

---

## Step 1｜建立 Google 試算表

1. 到 [Google 試算表](https://sheets.google.com) 新增一份空白試算表，取名如「划算度帳本」
2. 把分頁（下方標籤，預設叫「工作表1」）第一列填入標題：

   ```
   品項名稱  類別  克數  價格  CP值  新增時間
   ```

3. **匯入現有資料（可選）**：檔案 → 匯入 → 上傳 `初始資料匯入.csv` → 選擇「取代目前工作表的資料」或「插入新工作表」都可以，只要確認分頁名稱跟後面設定的一致

---

## Step 2｜部署 Google Apps Script（讓網站能讀寫試算表）

1. 在試算表上方選單點 **擴充功能 → Apps Script**，會開一個新分頁
2. 把預設的程式碼全部刪除，貼上 `Code.gs` 的內容
3. 把程式碼最上方的：
   ```js
   const SHEET_NAME = '工作表1';
   ```
   改成你實際的分頁名稱（在試算表最下方的標籤上可以看到）
4. 點右上角 **部署 → 新增部署作業**
   - 選取類型：齒輪圖示 → **網頁應用程式**
   - 說明：隨意填
   - 執行身份：**我**
   - 具有存取權的使用者：**所有人**
5. 點 **部署**，第一次會要求你授權（因為要讀寫你的試算表），照畫面指示允許即可
6. 部署完成後會出現一組網址，長得像：

   ```
   https://script.google.com/macros/s/AKfycb.......xyz/exec
   ```

   複製這組網址，等一下要貼到網站設定裡。

   > 之後如果你修改了 `Code.gs` 的內容，記得要「管理部署作業 → 編輯 → 版本選新版本 → 部署」，網址才會套用新程式碼。

---

## Step 3｜部署到 GitHub Pages

1. 到 GitHub 建立一個新的 repository（例如叫 `cp-tracker`），設定為 Public
2. 把 `index.html` 上傳到這個 repository 的根目錄（可以直接在網頁上用「Add file → Upload files」）
3. 進入 repository 的 **Settings → Pages**
4. 「Build and deployment」的 Source 選 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/ (root)`，按 Save
5. 等 1-2 分鐘，頁面會顯示你的網址，通常長得像：

   ```
   https://你的帳號.github.io/cp-tracker/
   ```

   手機、電腦打開這個網址都可以用。

---

## Step 4｜連結網站與試算表

1. 打開你部署好的網站
2. 點最下方「⚙ 設定同步網址」
3. 貼上 Step 2 拿到的 Apps Script 網址（`.../exec` 結尾）
4. 按「儲存網址」，畫面應該會自動載入試算表裡的資料

之後不管在手機還是電腦打開這個網站，只要貼過一次網址（存在瀏覽器本機），資料都會即時跟同一份 Google 試算表同步。家人朋友也可以打開同一個網址，各自貼上同一組 Apps Script 網址，一起共用同一份紀錄。

## 常見問題

**Q：新增後表格沒有更新？**
確認 `Code.gs` 裡的 `SHEET_NAME` 是否跟試算表分頁名稱完全一致（含全形/半形空白），並確認 Apps Script 部署時「誰可以存取」選的是「所有人」。

**Q：想要刪除試算表裡的資料？**
直接在網站表格右邊按 ✕，或直接到 Google 試算表裡手動刪除該列都可以，兩邊資料是同一份。

**Q：CP 值的顏色是怎麼算的？**
同一個類別裡，依 `$/g` 由低到高分成三等分：前 1/3 綠色（划算）、中間 1/3 黃色（普通）、後 1/3 紅色（偏貴）。跨類別比較（例如防曬乳 vs. 洗手乳）數字本身沒有太大意義，所以顏色只在同類別內比較。

**Q：資料會外流嗎？**
Apps Script 網址只有知道網址的人才能存取，且只能讀寫你指定的那份試算表，不會有其他資料外洩疑慮；但因為部署時選「所有人」可存取，請不要把網址公開分享在你不信任的地方。
